## 💻 Projetos em Destaque

### 🔹 Help Desk API
Sistema de gerenciamento de chamados desenvolvido com Java e Spring Boot, com operações CRUD, validações, tratamento de exceções e integração com MySQL.

### 🔹 API Produtos
API REST desenvolvida com Java e Spring Boot para gerenciamento de produtos, utilizando banco de dados MySQL.

### 🔹 Terror Memory
Jogo da memória temático de Halloween, desenvolvido com HTML, CSS e JavaScript, com sistema de pontuação, cronômetro e efeitos visuais.

### 🔹 Calculadora de IMC
Aplicação web para cálculo do Índice de Massa Corporal, desenvolvida com HTML, CSS e JavaScript.

### 🔹 Cálculo de Média Escolar
Aplicação web que calcula a média escolar e apresenta o resultado conforme as notas informadas pelo usuário.
