# Portfólio Profissional — Wilis Ítalo

Site pessoal responsivo desenvolvido com HTML, CSS e JavaScript.

## Conteúdo
- Apresentação e objetivo profissional
- Competências
- Experiências profissionais
- Formação acadêmica e cursos
- Projetos práticos
- Contatos

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou utilize a extensão Live Server.

## Personalização antes de publicar
- Revise telefone, e-mail, cidade e links.
- Confirme se todos os projetos estão públicos e funcionando.
- Se desejar, adicione uma foto profissional e um link para baixar o currículo em PDF.

## Tecnologias
HTML5, CSS3 e JavaScript.
